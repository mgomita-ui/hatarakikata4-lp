WEEKLY DRILL ｜ WEEK 3
第3週

作らせて、確かめて、直す（AI駆動開発）

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ねらい

第2週の見積作りを「毎月使える手順」にします。ここでの主役は「確かめる」です。確認の手順そのものを AI に用意させ、わざと壊れたデータを入れて、ちゃんと止まるかを見ます。AI に作らせて、人が確かめて直す（AI駆動開発）の一番小さな形です。

15分の手順

時間すること
0〜2分ai-drill で claude を動かす
2〜7分下のプロンプトで、見積作りを「毎月使える手順（スクリプト）」にし、確認手順も付けてもらう
7〜10分動かす：その手順を実行してもらい、自動の確認が通るのを見る
10〜13分確かめる：コピーした 受注データ_壊れ.csv に、単価が空欄の行を1行わざと作る。もう一度動かして、どう止まるか見る
13〜15分記録とダッシュボード（2分）：止まり方が不親切なら直してもらい、drill_log.md に1行。ダッシュボードに1枚足す（下記）

使うプロンプト例

先週作った見積のたたき台を、毎月くり返し使える手順（スクリプト）にして。
実行する前に「確認手順」も作って。少なくとも
・3ファイルの合計が、CSV から計算した合計と一致するか
・単価や数量が空欄の行があれば、そこで止まって行番号を教える
の2つは自動で確かめるように。
まず、どんな作りにするかを3行で先に言ってから作って。

壊して確かめるとき：

受注データ.csv をコピーして 受注データ_壊れ.csv を作り（研修当日のものが残っていればそれを使う）、その10行目の単価を空欄にしてから、壊れた方のファイルでもう一度実行して。受注データ.csv 自体は変えないで。
止まったら、何が原因で、どの行かを私に分かる言葉で表示して。

ダッシュボードに1枚足す

その週の結論と数字が、ダッシュボードの「確認と値上げ」に入ります。

今週（第3週）のドリルの結果を、ダッシュボードに1枚足して。

作る前に、次の4つを先に私に見せて、私の答えを待って。
① 結論（1〜2文）
② 数字（4つまで。どのファイルのどの行・どの列から取ったか。計算した数字は計算式も）
顧客名・個人名は、前提メモの「名前の扱い」に従う。
③ 次の一手（何を、誰が、いつまでに）
④ 人が決めること（1つの問い）と、いまの状態（未決・決定・保留）
専門家（社労士・税理士・弁護士）に確かめた方がよい点があれば、それも1つだけ挙げて。無ければ挙げない。

私が「OK」と言ったら、ファイルを読み直さずに、見せた内容のまま、次の2つだけを行って。
・dashboard/data/w（2桁の週番号）-（今の日付と時刻 YYYYMMDD-HHMM）.js を新しく作る
・dashboard/index.html の「WEEKS:END」の行のすぐ上に、<script src="data/そのファイル名"></script> を1行足す
既にあるファイルは書き換えない・消さない。同じ週をやり直したときも、新しい日時のファイルを足す（新しいものが表示される）。

ファイルの形（この形のまま埋める）
DASH.add({
  week: 3,
  date: "YYYY-MM-DD HH:MM",
  practice: （練習データなら true、自社の数字なら false）,
  title: "",
  conclusion: "",
  numbers: [ { label: "", value: 数字, unit: "", note: "" } ],
  source: "",
  next: { action: "", owner: "", due: "" },
  decision: { status: "（未決／決定／保留）", question: "", note: "" },
  expert: { topic: "", question: "" }
});
専門家に確かめる点が無ければ、expert の行は入れない。
