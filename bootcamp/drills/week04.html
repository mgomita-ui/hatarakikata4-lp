第4週

前提を先に言わせ、三通り出させる

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ねらい

研修当日の「三通りの比較：一日仕事 → その場で見比べる」を、自社の判断で使います。題材は当日と同じ「来期の値上げ、据え置き／3%／5%」。研修当日にやったものを、自社データでもう一度（顧客名を伏せた受注の書き出しで十分。用意がなければ受注データ.csv のままで構いません）。AI に前提を先に言わせ、三通りを表で出させ、最後に決めるのは自分。当日、講師が確かめた「前提を出させた」「比較させた」「聞き返した」と同じ動きです。

15分の手順

時間すること
0〜2分ai-drill で claude を動かす
2〜7分下のプロンプトで、前提3つ → 三通りの表 → 確認すべき点2つ、の順に出してもらう
7〜10分確かめる：前提3つのうち、自社と違うものを1つ見つけて言い直す
10〜13分直す：前提を直した結果、三通りの数字がどう変わったかを見る
13〜15分記録とダッシュボード（2分）：自分の判断を drill_log.md に1行（「今回は据え置き。理由は…」）。ダッシュボードに1枚足す（下記）

使うプロンプト例

受注データ.csv（自社の書き出しなら、そのファイル名）をもとに、来期の価格を「据え置き／3%値上げ／5%値上げ」の三通りで比べたい。
まず、この比較に必要な前提を3つ、あなたの仮置きの数字と一緒に先に言って
（例：値上げで失う受注の割合、原価率、単価の丸め方）。
次に、三通りを「売上・粗利・失注リスク」の表にして。
最後に、これはたたき台なので、私が決める前に確認すべき点を2つ挙げて。

ダッシュボードに1枚足す

その週の結論と数字が、ダッシュボードの「確認と値上げ」に入ります。

今週（第4週）のドリルの結果を、ダッシュボードに1枚足して。

作る前に、次の4つを先に私に見せて、私の答えを待って。
① 結論（1〜2文）
② 数字（4つまで。どのファイルのどの行・どの列から取ったか。計算した数字は計算式も）
顧客名・個人名は、前提メモの「名前の扱い」に従う。
③ 次の一手（何を、誰が、いつまでに）
④ 人が決めること（1つの問い）と、いまの状態（未決・決定・保留）
専門家（社労士・税理士・弁護士）に確かめた方がよい点があれば、それも1つだけ挙げて。無ければ挙げない。

私が「OK」と言ったら、ファイルを読み直さずに、見せた内容のまま、次の2つだけを行って。
・dashboard/data/w（2桁の週番号）-（今の日付と時刻 YYYYMMDD-HHMM）.js を新しく作る
・dashboard/index.html の「WEEKS:END」の行のすぐ上に、<script src="data/そのファイル名"></script> を1行足す
既にあるファイルは書き換えない・消さない。同じ週をやり直したときも、新しい日時のファイルを足す（新しいものが表示される）。

ファイルの形（この形のまま埋める）
DASH.add({
  week: 4,
  date: "YYYY-MM-DD HH:MM",
  practice: （練習データなら true、自社の数字なら false）,
  title: "",
  conclusion: "",
  numbers: [ { label: "", value: 数字, unit: "", note: "" } ],
  source: "",
  next: { action: "", owner: "", due: "" },
  decision: { status: "（未決／決定／保留）", question: "", note: "" },
  expert: { topic: "", question: "" }
});
専門家に確かめる点が無ければ、expert の行は入れない。
