WEEKLY DRILL ｜ WEEK 1
第1週

相棒が動くことを、毎晩確かめる

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ねらい

合宿で立ち上げた Claude Code と Codex が、自分のPCでまだ動くことを確かめます。そして「頼む → 動かす → 確かめる → 直す」を、15分の日課にします。今週は、練習用の受注データを AI に作らせるところまで。

15分の手順

時間すること
0〜2分ターミナルで ai-drill に移動し、claude を動かす
2〜8分下のプロンプトで、練習用の受注データ（CSV）を作ってもらう
8〜11分確かめる：できた CSV を Excel で開く。行数・列名・金額の単位を見る
11〜13分直す：気になった点を一つ、言葉で頼んで直してもらう
13〜15分記録：drill_log.md に今日の1行を書かせる

使うプロンプト例

このフォルダに、練習用の受注データを CSV で作って。
列は「受注日, 顧客名, 品目, 数量, 単価, 担当」、30行、直近3か月分。
顧客名と品目は実在しないものにして。
作る前に、前提（金額の単位・税込か税抜か・日付の形式）を先に言ってから作って。

直すとき：

単価は税抜に統一して、右端に「金額」（数量×単価）の列を足して。
直した箇所だけ教えて。

記録するとき：

drill_log.md に「第1週（今日の日付）：受注CSVを作成。（できた／詰まった点を一言）」と1行追記して。

もう片方の相棒でも

同じ最初のプロンプトを codex でも頼んでみてください。返事の仕方、聞き返し方が違います。どちらが自分の言葉に合うか、感触をつかむのが今週の隠れた課題です。

できたかの確認

  • ☐ claude と codex の両方が、自分のPCで動いた
  • ☐ 作る前に「前提」を先に言ってきた（言ってこなければ、次から頼み方に足す）
  • ☐ CSV が Excel で開けて、30行・金額列がある
  • ☐ drill_log.md に1行増えた
