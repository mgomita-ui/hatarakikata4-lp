WEEKLY DRILL ｜ WEEK 6
第6週

「先月の粗利は？」に、自社の数字で答える

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ねらい

研修当日の「先月の粗利は？」（経理に照会して数日 → つないだ数字をその場で）を、自社の数字で。研修当日にやったものを自社データでもう一度。今週からは自社の数字です。会計ソフトから月次の売上・原価を CSV で書き出し、ai-drill に置きます（顧客名は伏せて構いません）。大事なのは、AI に「粗利の定義」と「どの列を使ったか」を先に言わせること。当日 CLAUDE.md に残した定義があれば、それが自社の数字でも通るかを見ます。

15分の手順

時間すること
0〜3分会計ソフトから、先月の「売上」「売上原価」を CSV で書き出し、ai-drill に置く（会計ソフトに MCP があれば、claude mcp add で直接つないでも可）
3〜7分下のプロンプトで、粗利を一言で答えてもらう。根拠の表つき
7〜10分確かめる：会計ソフトの画面の粗利と照合する。ずれたら、定義か列がずれている
10〜13分直す：自社の粗利の定義を、CLAUDE.md（Codex なら AGENTS.md）に書いてもらう
13〜15分記録とダッシュボード（2分）：drill_log.md に1行。ダッシュボードに1枚足す（下記）

使うプロンプト例

先月の粗利は？
答える前に、粗利の定義（売上 − 売上原価）と、どのファイルのどの列を使うかを先に言って。
答えは一言。その下に、根拠になる表（売上・原価・粗利・粗利率）を付けて。
定義に迷う点（値引き・返品・運賃の扱い）があれば、私に聞き返して。

定義を残すとき：

いま確定した「うちの粗利の定義」を、CLAUDE.md に3行で追記して。次回から前提として使って。

ダッシュボードに1枚足す

その週の結論と数字が、ダッシュボードの「接続と粗利」に入ります。

今週（第6週）のドリルの結果を、ダッシュボードに1枚足して。

作る前に、次の4つを先に私に見せて、私の答えを待って。
① 結論（1〜2文）
② 数字（4つまで。どのファイルのどの行・どの列から取ったか。計算した数字は計算式も）
顧客名・個人名は、前提メモの「名前の扱い」に従う。
③ 次の一手（何を、誰が、いつまでに）
④ 人が決めること（1つの問い）と、いまの状態（未決・決定・保留）
専門家（社労士・税理士・弁護士）に確かめた方がよい点があれば、それも1つだけ挙げて。無ければ挙げない。

私が「OK」と言ったら、ファイルを読み直さずに、見せた内容のまま、次の2つだけを行って。
・dashboard/data/w（2桁の週番号）-（今の日付と時刻 YYYYMMDD-HHMM）.js を新しく作る
・dashboard/index.html の「WEEKS:END」の行のすぐ上に、<script src="data/そのファイル名"></script> を1行足す
既にあるファイルは書き換えない・消さない。同じ週をやり直したときも、新しい日時のファイルを足す（新しいものが表示される）。

ファイルの形（この形のまま埋める）
DASH.add({
  week: 6,
  date: "YYYY-MM-DD HH:MM",
  practice: （練習データなら true、自社の数字なら false）,
  title: "",
  conclusion: "",
  numbers: [ { label: "", value: 数字, unit: "", note: "" } ],
  source: "",
  next: { action: "", owner: "", due: "" },
  decision: { status: "（未決／決定／保留）", question: "", note: "" },
  expert: { topic: "", question: "" }
});
専門家に確かめる点が無ければ、expert の行は入れない。
