第12週

90日の振り返りと、次の90日

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ねらい

drill_log.md に、研修当日の第0行から第11週まで12行たまっています。AI に読ませ、「できるようになったこと／まだ詰まっていること／翌朝の経営会議で使えているもの」の三列に分け、次の90日の課題を3つ提案させる。あわせて、研修当日に線を引いた roles.md（人・AI・専門家の三列）を、実際に使った90日に合わせて直します。ダッシュボード（dashboard/index.html）も、会議モードで12週分を見返し、未決・保留のものから次の90日の課題を選ぶ材料にします。決めるのはあなた。月次1on1に持って来てください。

15分の手順

時間すること
0〜2分claude を動かす。drill_log.md・roles.md（研修当日に作り、第10週で直したもの）・dashboard/index.html が ai-drill にあることを確かめる
2〜7分下のプロンプトで、三列の振り返りと、次の90日の課題3つを出してもらう
7〜10分確かめる：「使えているもの」の列に、本当に会議で使ったものだけが入っているか
10〜13分直す：roles.md を、90日で実際に AI に渡せた仕事・渡せなかった仕事で直してもらう。動かした業務と理由を1行ずつ。たたき台として保存
13〜15分記録とダッシュボード（2分）：次の90日で最初にやる1つを drill_log.md の最後に1行。ダッシュボードに1枚足す（下記）

ダッシュボードに1枚足す

その週の結論と数字が、ダッシュボードの「引継ぎと90日」に入ります。

今週（第12週）のドリルの結果を、ダッシュボードに1枚足して。

作る前に、次の4つを先に私に見せて、私の答えを待って。
① 結論（1〜2文）
② 数字（4つまで。どのファイルのどの行・どの列から取ったか。計算した数字は計算式も）
顧客名・個人名は、前提メモの「名前の扱い」に従う。
③ 次の一手（何を、誰が、いつまでに）
④ 人が決めること（1つの問い）と、いまの状態（未決・決定・保留）
専門家（社労士・税理士・弁護士）に確かめた方がよい点があれば、それも1つだけ挙げて。無ければ挙げない。

私が「OK」と言ったら、ファイルを読み直さずに、見せた内容のまま、次の2つだけを行って。
・dashboard/data/w（2桁の週番号）-（今の日付と時刻 YYYYMMDD-HHMM）.js を新しく作る
・dashboard/index.html の「WEEKS:END」の行のすぐ上に、<script src="data/そのファイル名"></script> を1行足す
既にあるファイルは書き換えない・消さない。同じ週をやり直したときも、新しい日時のファイルを足す（新しいものが表示される）。

ファイルの形（この形のまま埋める）
DASH.add({
  week: 12,
  date: "YYYY-MM-DD HH:MM",
  practice: （練習データなら true、自社の数字なら false）,
  title: "",
  conclusion: "",
  numbers: [ { label: "", value: 数字, unit: "", note: "" } ],
  source: "",
  next: { action: "", owner: "", due: "" },
  decision: { status: "（未決／決定／保留）", question: "", note: "" },
  expert: { topic: "", question: "" }
});
専門家に確かめる点が無ければ、expert の行は入れない。
