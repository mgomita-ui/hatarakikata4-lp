WEEKLY DRILL ｜ WEEK 8
第8週

計算は Codex、文章は Claude

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ねらい

研修の3つ目の約束、「AI を分けて組み合わせ、三通り出させる」。当日の最後にやった「計算は Codex、文章は Claude で5行の報告文」を、自社の数字でもう一度。計算は答えが一つに決まる仕事、文章は読み手で変わる仕事。だから相棒を分けます。Codex に部門別の粗利率を計算させ、その結果を Claude に渡して経営会議向けの報告文にする。最後に、文章の中の数字が Codex の数字と一致するかを確かめます。

15分の手順

時間すること
0〜5分codex で、第6週の CSV から部門別（または顧客別）の粗利率を計算し、gross_margin.csv に書き出してもらう
5〜9分claude で、その CSV を読ませ、経営会議向けの5行の報告文を作ってもらう
9〜12分確かめる：報告文の数字を、gross_margin.csv と1つずつ照合する。数字が変わっていないか
12〜13分三通り：同じ報告文を「社員向け／銀行向け／自分用」で三通り出してもらう
13〜15分記録とダッシュボード（2分）：drill_log.md に1行。ダッシュボードに1枚足す（下記）

使うプロンプト例

Codex に（計算）：

売上.csv と原価.csv から、部門別の売上・原価・粗利・粗利率を計算して gross_margin.csv に書き出して。
計算式も表示して。数字の丸めは小数1桁。

Claude に（文章）：

gross_margin.csv を読んで、明日の経営会議向けの報告文を5行で。
数字は CSV のまま、1つも変えないで。
最後に「この数字の前提」と「注意点」を1行ずつ。

三通り：

同じ内容を「社員向け（30秒で読める）」「銀行向け（丁寧に）」「自分用（打ち手だけ）」の三通りで。
数字は変えないで。

ダッシュボードに1枚足す

その週の結論と数字が、ダッシュボードの「議事録と報告」に入ります。

今週（第8週）のドリルの結果を、ダッシュボードに1枚足して。

作る前に、次の4つを先に私に見せて、私の答えを待って。
① 結論（1〜2文）
② 数字（4つまで。どのファイルのどの行・どの列から取ったか。計算した数字は計算式も）
顧客名・個人名は、前提メモの「名前の扱い」に従う。
③ 次の一手（何を、誰が、いつまでに）
④ 人が決めること（1つの問い）と、いまの状態（未決・決定・保留）
専門家（社労士・税理士・弁護士）に確かめた方がよい点があれば、それも1つだけ挙げて。無ければ挙げない。

私が「OK」と言ったら、ファイルを読み直さずに、見せた内容のまま、次の2つだけを行って。
・dashboard/data/w（2桁の週番号）-（今の日付と時刻 YYYYMMDD-HHMM）.js を新しく作る
・dashboard/index.html の「WEEKS:END」の行のすぐ上に、<script src="data/そのファイル名"></script> を1行足す
既にあるファイルは書き換えない・消さない。同じ週をやり直したときも、新しい日時のファイルを足す（新しいものが表示される）。

ファイルの形（この形のまま埋める）
DASH.add({
  week: 8,
  date: "YYYY-MM-DD HH:MM",
  practice: （練習データなら true、自社の数字なら false）,
  title: "",
  conclusion: "",
  numbers: [ { label: "", value: 数字, unit: "", note: "" } ],
  source: "",
  next: { action: "", owner: "", due: "" },
  decision: { status: "（未決／決定／保留）", question: "", note: "" },
  expert: { topic: "", question: "" }
});
専門家に確かめる点が無ければ、expert の行は入れない。
