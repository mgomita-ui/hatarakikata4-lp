WEEKLY DRILL ｜ WEEK 10
第10週

人・AI・専門家の三列

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ねらい

研修当日の最後に仮置きした三列「人がすること・AI がすること・専門家がすることの線」を、自社の全業務でもう一度。当日の roles.md があれば、それを読ませてから直します。AI に棚卸しと仮置きをさせ、迷うものには「？」を付けさせる。人を減らすためではなく、人を人にしかできない仕事に戻すためです。最後に「明日 AI に渡す1つ」を決めます。

15分の手順

時間すること
0〜2分claude を動かす。CLAUDE.md に業種・社員数が入っていることを確かめる
2〜7分下のプロンプトで、業務20個を三列に仮置きしてもらう
7〜11分確かめる：仮置きのうち、自分の実感と違うものを5つ動かす（AI → 人、など）
11〜13分直す：決定版を roles.md に保存。「明日 AI に渡す1つ」に印
13〜15分記録とダッシュボード（2分）：drill_log.md に1行。ダッシュボードに1枚足す（下記）

使うプロンプト例

うちの業務を20個、部門をまたいで列挙して（CLAUDE.md の業種・規模を前提に）。
研修当日の roles.md があれば先に読んで、その20個を土台にして。
それぞれを「AI がする／人がする／専門家がする」の三列に仮置きして、理由を一言ずつ。
迷うものには「？」を付けて。決めるのは私なので、断定しないで。
「専門家」は労務・法務・税務・会計のような、資格や責任が要る仕事。

直すとき：

「請求書の作成」は AI へ、「値引きの決定」は人へ、「就業規則の改定」は専門家へ動かして。
決定版を roles.md に保存して、AI の列から「明日から渡す1つ」を私が選ぶので候補を3つ。

ダッシュボードに1枚足す

その週の結論と数字が、ダッシュボードの「納期と役割」に入ります。専門家に確かめたい点（離職率の数え方、業務委託の線引き など）があれば、ダッシュボードのカードから社労士に聞けます。無理に作らなくて構いません。

今週（第10週）のドリルの結果を、ダッシュボードに1枚足して。

作る前に、次の4つを先に私に見せて、私の答えを待って。
① 結論（1〜2文）
② 数字（4つまで。どのファイルのどの行・どの列から取ったか。計算した数字は計算式も）
顧客名・個人名は、前提メモの「名前の扱い」に従う。
③ 次の一手（何を、誰が、いつまでに）
④ 人が決めること（1つの問い）と、いまの状態（未決・決定・保留）
専門家（社労士・税理士・弁護士）に確かめた方がよい点があれば、それも1つだけ挙げて。無ければ挙げない。

私が「OK」と言ったら、ファイルを読み直さずに、見せた内容のまま、次の2つだけを行って。
・dashboard/data/w（2桁の週番号）-（今の日付と時刻 YYYYMMDD-HHMM）.js を新しく作る
・dashboard/index.html の「WEEKS:END」の行のすぐ上に、<script src="data/そのファイル名"></script> を1行足す
既にあるファイルは書き換えない・消さない。同じ週をやり直したときも、新しい日時のファイルを足す（新しいものが表示される）。

ファイルの形（この形のまま埋める）
DASH.add({
  week: 10,
  date: "YYYY-MM-DD HH:MM",
  practice: （練習データなら true、自社の数字なら false）,
  title: "",
  conclusion: "",
  numbers: [ { label: "", value: 数字, unit: "", note: "" } ],
  source: "",
  next: { action: "", owner: "", due: "" },
  decision: { status: "（未決／決定／保留）", question: "", note: "" },
  expert: { topic: "", question: "" }
});
専門家に確かめる点が無ければ、expert の行は入れない。
