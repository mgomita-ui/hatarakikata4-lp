第5週

MCP の1本目：自社のフォルダをつなぐ

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ねらい

研修当日に通した MCP の1本を、自分のPCでもう一度。今週は一番身近な「フォルダ」をつなぎます。当日、会計ソフトの MCP でつないだ人も、まずフォルダから。AI は渡した情報しか知りません。MCP はその「配線口」です。つながると、ファイルを毎回貼らなくても「先月の上位3顧客は？」に答えてくれます。

15分の手順

時間すること
0〜5分ターミナルで ai-drill に移動し claude を動かす。/mcp に drill-files（研修当日につないだフォルダ）が出るか確かめる。出なければ下のコマンドを一度だけ
5〜9分claude の中で下のプロンプト。ファイルを貼らずに答えが返るかを見る
9〜12分確かめる：返ってきた上位3社を、Excel の並べ替えで照合する
12〜13分直す：「どのファイルを読んだか」を先に言わせる形に、頼み方を直す
13〜15分記録とダッシュボード（2分）：drill_log.md に1行。ダッシュボードに1枚足す（下記）

つながっていないときは、ターミナルで次を動かします。研修当日に済ませてあれば、/mcp で drill-files が見えるかだけ確かめて、この枠は飛ばしてください。

Windows（PowerShell）。（ユーザー名） は自分のものに。エクスプローラーで ai-drill を開き、上のアドレス欄に出る場所をそのまま貼っても構いません。

claude mcp add drill-files -- cmd /c npx -y @modelcontextprotocol/server-filesystem C:\Users\（ユーザー名）\Desktop\ai-drill

Mac（ターミナル）。

claude mcp add drill-files -- npx -y @modelcontextprotocol/server-filesystem ~/Desktop/ai-drill

つながったかは claude の中で /mcp と入力すると一覧で見えます。

ダッシュボードに1枚足す

その週の結論と数字が、ダッシュボードの「接続と粗利」に入ります。

今週（第5週）のドリルの結果を、ダッシュボードに1枚足して。

作る前に、次の4つを先に私に見せて、私の答えを待って。
① 結論（1〜2文）
② 数字（4つまで。どのファイルのどの行・どの列から取ったか。計算した数字は計算式も）
顧客名・個人名は、前提メモの「名前の扱い」に従う。
③ 次の一手（何を、誰が、いつまでに）
④ 人が決めること（1つの問い）と、いまの状態（未決・決定・保留）
専門家（社労士・税理士・弁護士）に確かめた方がよい点があれば、それも1つだけ挙げて。無ければ挙げない。

私が「OK」と言ったら、ファイルを読み直さずに、見せた内容のまま、次の2つだけを行って。
・dashboard/data/w（2桁の週番号）-（今の日付と時刻 YYYYMMDD-HHMM）.js を新しく作る
・dashboard/index.html の「WEEKS:END」の行のすぐ上に、<script src="data/そのファイル名"></script> を1行足す
既にあるファイルは書き換えない・消さない。同じ週をやり直したときも、新しい日時のファイルを足す（新しいものが表示される）。

ファイルの形（この形のまま埋める）
DASH.add({
  week: 5,
  date: "YYYY-MM-DD HH:MM",
  practice: （練習データなら true、自社の数字なら false）,
  title: "",
  conclusion: "",
  numbers: [ { label: "", value: 数字, unit: "", note: "" } ],
  source: "",
  next: { action: "", owner: "", due: "" },
  decision: { status: "（未決／決定／保留）", question: "", note: "" },
  expert: { topic: "", question: "" }
});
専門家に確かめる点が無ければ、expert の行は入れない。

今週の変更点（2026年9月6日時点）

  • MCP の新しい仕様（2026-07-28版）が出ました。 サーバー側が「普通の Web サービスと同じ形」で動かせるようになり、会計・勤怠などの SaaS 各社が MCP を出しやすくなりました。受講者への影響は「つなげる先が増える」こと。お使いの会計ソフトに MCP があるか、会計ソフトの案内ページか claude mcp list で月に一度見てください。無ければ CSV 書き出し → フォルダ MCP で十分です。（2026年7月28日公開、8月以降に各社対応）
