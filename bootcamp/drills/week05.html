第5週

MCP の1本目：自社のフォルダをつなぐ

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ねらい

合宿で通した MCP の1本を、自分のPCでもう一度。今週は一番身近な「フォルダ」をつなぎます。AI は渡した情報しか知りません。MCP はその「配線口」です。つながると、ファイルを毎回貼らなくても「先月の上位3顧客は？」に答えてくれます。

15分の手順

時間すること
0〜5分Claude Desktop の「設定 → コネクタ（拡張機能）」で、ローカルフォルダ（Filesystem）を追加し、ai-drill を許可する
5〜9分Claude Desktop のチャットで、下のプロンプト。ファイルを貼らずに答えが返るかを見る
9〜12分確かめる：返ってきた上位3社を、Excel の並べ替えで照合する
12〜14分直す：「どのファイルを読んだか」を先に言わせる形に、頼み方を直す
14〜15分記録：drill_log.md に1行

Claude Code でつなぐ場合は、ターミナルで次を動かします（フォルダの場所は自分のものに）。

claude mcp add drill-files -- npx -y @modelcontextprotocol/server-filesystem ~/Desktop/ai-drill

つながったかは claude の中で /mcp と入力すると一覧で見えます。

使うプロンプト例

ai-drill フォルダの受注データ.csv を読んで、先月の受注金額が多い顧客を上から3社、金額つきで。
読む前に、どのファイルのどの列を使うかを先に言って。

直すとき：

「担当」別にも同じ表を出して。数字の根拠になった行数も添えて。

もう片方の相棒でも

Codex にも同じフォルダをつなげます。

codex mcp add drill-files -- npx -y @modelcontextprotocol/server-filesystem ~/Desktop/ai-drill

できたかの確認

  • ☐ ファイルを貼らずに、フォルダの中身をもとに答えが返った
  • ☐ 上位3社が、Excel の並べ替えと一致した
  • ☐ 「どのファイル・どの列を使ったか」を AI が先に言った

今週のAI係数：前提を出させた（どのファイル・どの列か）

今週の変更点（2026年9月6日時点）

  • MCP の新しい仕様（2026-07-28版）が出ました。 サーバー側が「普通の Web サービスと同じ形」で動かせるようになり、会計・勤怠などの SaaS 各社が MCP を出しやすくなりました。受講者への影響は「つなげる先が増える」こと。お使いの会計ソフトに MCP があるか、Claude Desktop のコネクタ一覧で月に一度見てください。無ければ CSV 書き出し → フォルダ MCP で十分です。（2026年7月28日公開、8月以降に各社対応）

出典：https://code.claude.com/docs/en/changelog
