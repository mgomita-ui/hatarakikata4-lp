はじめに：使い方と、最初の準備（10分）

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

レリック社会保険労務士法人　AI経営 × クエスト型ブートキャンプ　受講者向け 最終更新：2026年9月17日（「今週の変更点」は配信週に改定します）

このドリルの使い方

  • 毎週月曜の朝に1回分が届きます。 1回15分。同じ回を毎晩15分くり返しても効きます（同じ課題を、違う自社データでもう一度）。
  • 型はいつも同じです。 「頼む → 動かす → 確かめる → 直す」。15分で終わらなければ、そこで止めて「どこで止まったか」を1行だけ記録してください。次の週に効きます。
  • AIは相棒です。 同僚に頼むのと同じで、前提を先に伝え、返ってきたものはたたき台として受け取り、分からない点は聞き返してもらいます。決めるのは、あなたです。
  • 毎週の最後の2分で、研修当日に作った経営ダッシュボードに1枚足します。 空いた週は点線で残るので、続けているかが一目で分かります。
  • 研修の3つの約束と揃えてあります。
  • ① Claude Code と Codex が、自分のPCで動く（第1・2・3・7・11週）
  • ② AIが、会社のシステムにつながって動かす。MCP で自社の数字に（第5・6・9週）
  • ③ 人がすること・AIがすること・専門家がすることの線が引ける。計算は Codex、文章は Claude（第4・8・10・12週）

研修当日の「反復AIドリル」との関係

  • 研修当日の5つのワークを、12週に散らしてあります。当日は練習データで一度、ここでは自社のデータで同じ動きをします。
研修当日何をしたか毎週ドリルでは
WORK 01（0:00〜）今日やる仕事を決める。前提メモ（CLAUDE.md／AGENTS.md）と道具の確認第0週の準備、第1週（相棒が動くか）
WORK 02（0:15〜）頼んで、動かして、確かめて、直す。見積3社分／議事録／据え置き・3%・5%の三通り見積：第2・3週／三通り：第4週／議事録：第7週／計算は Codex、文章は Claude：第8週
WORK 03（1:25〜）つなぐ・動かす。MCP で「先月の粗利は？」、画面操作を1回MCP：第5・6週／毎朝動く仕組み：第9週。画面操作は毎週ドリルには入れていません。本番の画面に使うのは、月次1on1で相談のうえで
WORK 04（2:05〜）自社の仕事を1件第6週から自社の数字で。第11週で同僚に渡す形に
WORK 05（2:40〜）線を引く。人・AI・専門家の三列（roles.md）、drill_log.md の第0行第10週（三列をもう一度）／第12週（drill_log.md を読み返し、roles.md を直す）
  • 当日の反復AIドリルでくり返した5つの作業、集める・要約・比べる・洗い出す・分析する も、そのまま散らしてあります。集める（第1・5週）／要約（第7週）／比べる（第4・8・12週）／洗い出す（第9・10・11週）／分析する（第6・8週）。
  • 当日、講師が確かめた5つの動き、「前提を出させた」「比較させた」「リスクを出させた」「聞き返した」「改善に使った」を、各週の最後に「今週の5つの動き」として載せています。毎週1つ以上、必ず入ります。
  • 当日と同じで、触った回数がそのまま技になります。読むだけの週を作らないでください。

最初の一度だけ：準備（10分）

  1. 研修当日に使ったフォルダ、デスクトップの ai-drill をそのまま使います。無ければ、同じ名前で作ります。研修当日のデータ（受注データ.csv、会議_文字起こし.txt、売上.csv、原価.csv）と、当日作ったもの（見積_A社.xlsx など）が入っているはずです。
  2. ターミナル（Windows は PowerShell、Mac はターミナル）を開き、そのフォルダに移動します。
cd ~/Desktop/ai-drill
  1. Claude Code と Codex が動くことを確かめます。どちらも研修の前に、事前セットアップで立ち上げたものです。
claude
codex
  1. フォルダに「前提メモ」があることを確かめます。Claude Code は CLAUDE.md、Codex は AGENTS.md という名前のファイルを読んで、毎回の前提にします。研修当日に、はじめの設定プロンプトで作ったものがそのまま使えます。無ければ、3行で作ります。
- 会社：（社名・業種・社員数）
- ルール：作る前に前提を先に言う。分からない点は聞き返す。最終確認は私がする。
- 単位：金額は円・税抜。日付は日本時間。
  1. drill_log.md があることを確かめます。研修当日の最後に、第0行「研修当日：できたこと／詰まったこと」を書いたファイルです。無ければ空のファイルを作ります。毎週の最後に1行ずつ足していきます。第12週で読み返します。
  2. ai-drill に dashboard フォルダがあることを確かめます。研修当日、はじめの設定プロンプトで作った経営ダッシュボード（dashboard/index.html と dashboard/data/）です。無ければ、講師に連絡してください。

自社データの扱い

第3週までは、研修当日と同じ練習データ（架空の受注データ.csv）で進みます。第4週から自社の数字を使えます（用意がなければ練習データのままで構いません）。第6週からは自社の数字を使いますが、顧客名を伏せた書き出しファイルで十分です。研修の冒頭で説明した通り、どこまで渡すかはあなたの判断で選べます。

付録：頼み方の型（研修当日と同じ6行。いつでも使える）

（何を）　　……を作って／出して。
（前提）　　作る前に、前提を先に言って。分からない点は私に聞き返して。
（材料）　　読むのは……（ファイル名）。書かれていないことは補わない。
（形）　　　結果は……の形で（ファイル名・項目・文字数）。
（確認）　　……が一致するかを自動で確かめて。送信・削除はしない。
（決める）　これはたたき台。決めるのは私。
