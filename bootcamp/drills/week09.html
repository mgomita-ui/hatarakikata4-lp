第9週

毎朝、勝手に出る納期リスク

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ねらい

合宿の「納期リスク：毎朝、勝手に出る」。定型の報告は AI に渡し、人は朝それを見て決める側に回ります。今週は「納期まで7日以内で未出荷」の一覧を、毎朝9時に自動で作る仕組みを作ります。仕組みは AI に作らせ、翌朝ファイルが増えているかを人が確かめます。

15分の手順

時間すること
0〜3分claude で、受注データに「納期」「出荷済み」の2列を足してもらう（練習データで可）
3〜8分下のプロンプトで、リスク一覧を作る手順と、毎朝9時に動かす仕組みを作ってもらう
8〜11分動かす：一度、手で実行して daily_risk.md ができるのを見る
11〜14分直す：並び順の基準（納期が近い順か、金額が大きい順か）を自分の言葉で決めて直す
14〜15分記録：drill_log.md に1行。翌朝9時5分に確かめる予定を手帳に

使うプロンプト例

受注データ.csv から「納期まで7日以内で、出荷済みでない案件」を一覧にする手順を作って。
並びは納期が近い順、次に金額が大きい順。
結果は daily_risk.md に、日付つきで上に追記する形で。
これを毎朝9時に自動で動かしたい。Claude Code の定期実行（/schedule）で組める？
無理なら、Windows のタスクスケジューラで動かす手順を教えて。作る前に、作りを3行で先に。

直すとき：

並び順を「金額が大きい順、次に納期が近い順」に変えて。理由：まず大口を守りたい。

できたかの確認

  • ☐ 手で実行して、daily_risk.md に一覧が出た
  • ☐ 毎朝9時の定期実行が設定できた（Claude Code の /schedule、またはタスクスケジューラで codex exec を回す）
  • ☐ 翌朝、見に行って増えていた（増えていなければ、次の15分でそこを直す）

今週のAI係数：リスクを出させた（納期リスク一覧）／改善に使った（並び順を自分で決めて直す）
