WEEKLY DRILL ｜ 全12週

毎週届く、15分のドリル

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ブートキャンプの受講者に、毎週月曜の朝に1回ずつ届く15分のドリルです。型はいつも「頼む → 動かす → 確かめる → 直す」。合宿の3つの約束（Claude Code と Codex が自分のPCで動く／MCP で自社の数字につながる／計算は Codex、文章は Claude）と揃えてあります。

第0週　はじめに：使い方と、最初の準備（10分） から始めてください。

第1週相棒が動くことを、毎晩確かめる
合宿で立ち上げた Claude Code と Codex が、自分のPCでまだ動くことを確かめます。そして「頼む → 動かす → 確かめる → 直す」を、15分の日課にします。今週は、練習用の受注データを AI に作らせるところまで。
第2週見積3社分のたたき台（バイブコーディング）
合宿の「見積3社分：3時間 → 30秒」を、自分のPCでもう一度。日本語で頼んで、動くものを作る（バイブコーディング）の型を体に入れます。返ってきた見積は完成品ではなく、たたき台です。
第3週作らせて、確かめて、直す（AI駆動開発）
第2週の見積作りを「毎月使える手順」にします。ここでの主役は「確かめる」です。確認の手順そのものを AI に用意させ、わざと壊れたデータを入れて、ちゃんと止まるかを見ます。AI に作らせて、人が確かめて直す（AI駆動開発）の一番小さな形です。
第4週前提を先に言わせ、三通り出させる
合宿の「三通りの比較：半日 → 2分」を、自社の判断で使います。今週の題材は「来期の値上げ」。AI に前提を先に言わせ、三通りを表で出させ、最後に決めるのは自分。合宿で「前提を出させた」「比較させた」「聞き返した」が AI係数を上げたのと同じ動きです。
第5週MCP の1本目：自社のフォルダをつなぐ
合宿で通した MCP の1本を、自分のPCでもう一度。今週は一番身近な「フォルダ」をつなぎます。AI は渡した情報しか知りません。MCP はその「配線口」です。つながると、ファイルを毎回貼らなくても「先月の上位3顧客は？」に答えてくれます。
第6週「先月の粗利は？」に、自社の数字で答える
合宿の「粗利の確認：3日 → 一言」を、自社の数字で。今週から実データです。会計ソフトから月次の売上・原価を CSV で書き出し、ai-drill に置きます（顧客名は伏せて構いません）。大事なのは、AI に「粗利の定義」と「どの列を使ったか」を先に言わせること。
第7週議事録：会議中に
合宿の「議事録：2時間 → 会議中に」を、次の会議で。録音の文字起こし（スマホの録音アプリや会議ツールの文字起こし）を渡し、決定事項・宿題・保留に分けてもらいます。あいまいな箇所には「要確認」の印を付けさせ、聞き返してもらう。会議が終わる前に、議事録が終わっている状態を作ります。
第8週計算は Codex、文章は Claude
合宿の3枚目「AI を分けて組み合わせ、三通り出させる」。計算は答えが一つに決まる仕事、文章は読み手で変わる仕事。だから相棒を分けます。Codex に部門別の粗利率を計算させ、その結果を Claude に渡して経営会議向けの報告文にする。最後に、文章の中の数字が Codex の数字と一致するかを確かめます。
第9週毎朝、勝手に出る納期リスク
合宿の「納期リスク：毎朝、勝手に出る」。定型の報告は AI に渡し、人は朝それを見て決める側に回ります。今週は「納期まで7日以内で未出荷」の一覧を、毎朝9時に自動で作る仕組みを作ります。仕組みは AI に作らせ、翌朝ファイルが増えているかを人が確かめます。
第10週人・AI・専門家の三列
合宿の3枚目「人がすること・AI がすること・専門家がすることの線が引ける」を、自社の全業務で。AI に棚卸しと仮置きをさせ、迷うものには「？」を付けさせる。人を減らすためではなく、人を人にしかできない仕事に戻すためです。最後に「明日 AI に渡す1つ」を決めます。
第11週小さなツールを、同僚が使える形に
合宿の「自分で、小さなツールを作る。作ったものが翌日の仕事で使える」。第3週の見積スクリプト、または第9週の納期リスクを、AI を使ったことのない同僚が「読んで動かせる」形にします。README 3行、入力ファイルの置き場所、エラーのときの表示。作るのは AI、確かめるのは自分、渡すのは翌日。
第12週90日の振り返りと、次の90日
drill_log.md に11行たまっています。AI に読ませ、「できるようになったこと／まだ詰まっていること／翌朝の経営会議で使えているもの」の三列に分け、次の90日の課題を3つ提案させる。あわせて、合宿で持ち帰った「AI 経営チーム設計図（CMO・CFO・CTO・CIO 4役の定義書）」を、実際に使った90日に合わせて直します。決めるのはあなた。月次1on1に持って来てください。
