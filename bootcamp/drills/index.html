WEEKLY DRILL ｜ 全12週

毎週届く、15分のドリル

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ブートキャンプの受講者に、毎週月曜の朝に1回ずつ届く15分のドリルです。型はいつも「頼む → 動かす → 確かめる → 直す」。研修の3つの約束（Claude Code と Codex が、自分のPCで動く／AIが、会社のシステムにつながって動かす／人がすること・AIがすること・専門家がすることの線が引ける）と揃えてあります。各週の末尾の「今週の報告を送る」で、できた／詰まったを1行で知らせてください。

第0週　はじめに：使い方と、最初の準備（10分） から始めてください。

第1週相棒が動くことを、毎晩確かめる
研修の前に立ち上げた Claude Code と Codex が、自分のPCでまだ動くことを確かめます。そして「頼む → 動かす → 確かめる → 直す」を、15分の日課にします。今週の材料は受注データ.csv。研修当日に使ったものが ai-drill にあれば、それを使います。無ければ、AI に作らせます。
第2週見積3社分のたたき台（バイブコーディング）
研修当日の「見積3社分：半日がかり → その場で」を、自分のPCでもう一度。日本語で頼んで、動くものを作る（バイブコーディング）の型を体に入れます。当日は講師の実演のあとに一度やっています。今度は、聞き返しに自分で答えるところまで一人で。返ってきた見積は完成品ではなく、たたき台です。
第3週作らせて、確かめて、直す（AI駆動開発）
第2週の見積作りを「毎月使える手順」にします。ここでの主役は「確かめる」です。確認の手順そのものを AI に用意させ、わざと壊れたデータを入れて、ちゃんと止まるかを見ます。AI に作らせて、人が確かめて直す（AI駆動開発）の一番小さな形です。
第4週前提を先に言わせ、三通り出させる
研修当日の「三通りの比較：一日仕事 → その場で見比べる」を、自社の判断で使います。題材は当日と同じ「来期の値上げ、据え置き／3%／5%」。研修当日にやったものを、自社データでもう一度（顧客名を伏せた受注の書き出しで十分。用意がなければ受注データ.csv のままで構いません）。AI に前提を先に言わせ、三通りを表で出させ、最後に決めるのは自分。当日、講師が確かめた「前提を出させた」「比較させた」「聞き返した」と同じ動きです。
第5週MCP の1本目：自社のフォルダをつなぐ
研修当日に通した MCP の1本を、自分のPCでもう一度。今週は一番身近な「フォルダ」をつなぎます。当日、会計ソフトの MCP でつないだ人も、まずフォルダから。AI は渡した情報しか知りません。MCP はその「配線口」です。つながると、ファイルを毎回貼らなくても「先月の上位3顧客は？」に答えてくれます。
第6週「先月の粗利は？」に、自社の数字で答える
研修当日の「先月の粗利は？」（経理に照会して数日 → つないだ数字をその場で）を、自社の数字で。研修当日にやったものを自社データでもう一度。今週からは自社の数字です。会計ソフトから月次の売上・原価を CSV で書き出し、ai-drill に置きます（顧客名は伏せて構いません）。大事なのは、AI に「粗利の定義」と「どの列を使ったか」を先に言わせること。当日 CLAUDE.md に残した定義があれば、それが自社の数字でも通るかを見ます。
第7週議事録：会議中に
研修当日の「会議の文字起こし → 議事録。決定事項だけ箇条書き」を、次の会議で。研修当日にやったものを自社データでもう一度。録音の文字起こし（スマホの録音アプリや会議ツールの文字起こし）を渡し、決定事項・宿題・保留に分けてもらいます。あいまいな箇所には「要確認」の印を付けさせ、聞き返してもらう。会議が終わる前に、議事録が終わっている状態を作ります。
第8週計算は Codex、文章は Claude
研修の3つ目の約束、「AI を分けて組み合わせ、三通り出させる」。当日の最後にやった「計算は Codex、文章は Claude で5行の報告文」を、自社の数字でもう一度。計算は答えが一つに決まる仕事、文章は読み手で変わる仕事。だから相棒を分けます。Codex に部門別の粗利率を計算させ、その結果を Claude に渡して経営会議向けの報告文にする。最後に、文章の中の数字が Codex の数字と一致するかを確かめます。
第9週毎朝、勝手に出る納期リスク
研修当日の三列で「AI がする」に置いた「定型の報告」を、実際に毎朝動かします。定型の報告は AI に渡し、人は朝それを見て決める側に回ります。今週は「納期まで7日以内で未出荷」の一覧を、毎朝9時に自動で作る仕組みを作ります。仕組みは AI に作らせ、翌朝ファイルが増えているかを人が確かめます。
第10週人・AI・専門家の三列
研修当日の最後に仮置きした三列「人がすること・AI がすること・専門家がすることの線」を、自社の全業務でもう一度。当日の roles.md があれば、それを読ませてから直します。AI に棚卸しと仮置きをさせ、迷うものには「？」を付けさせる。人を減らすためではなく、人を人にしかできない仕事に戻すためです。最後に「明日 AI に渡す1つ」を決めます。
第11週小さなツールを、同僚が使える形に
研修の約束②にある「必要な仕組みを、その場で作る」の続き。作ったものを、翌日の仕事で同僚が使える形にします。第3週の見積スクリプト、または第9週の納期リスクを、AI を使ったことのない同僚が「読んで動かせる」形にします。README 3行、入力ファイルの置き場所、エラーのときの表示。作るのは AI、確かめるのは自分、渡すのは翌日。
第12週90日の振り返りと、次の90日
drill_log.md に、研修当日の第0行から第11週まで12行たまっています。AI に読ませ、「できるようになったこと／まだ詰まっていること／翌朝の経営会議で使えているもの」の三列に分け、次の90日の課題を3つ提案させる。あわせて、研修当日に線を引いた roles.md（人・AI・専門家の三列）を、実際に使った90日に合わせて直します。ダッシュボード（dashboard/index.html）も、会議モードで12週分を見返し、未決・保留のものから次の90日の課題を選ぶ材料にします。決めるのはあなた。月次1on1に持って来てください。
