見積3社分のたたき台（バイブコーディング）

1回15分。頼む → 動かす → 確かめる → 直す。決めるのは、あなた。

ねらい

研修当日の「見積3社分：半日がかり → その場で」を、自分のPCでもう一度。日本語で頼んで、動くものを作る（バイブコーディング）の型を体に入れます。当日は講師の実演のあとに一度やっています。今度は、聞き返しに自分で答えるところまで一人で。返ってきた見積は完成品ではなく、たたき台です。

15分の手順

時間すること
0〜2分ai-drill で claude を動かす。受注データ.csv があることを確かめる
2〜8分下のプロンプトで、見積3社分を Excel で作ってもらう。聞き返しが来たら答える
8〜12分確かめる：3ファイルできたか。1社だけ、合計を電卓で照合する
12〜13分直す：足りない行（有効期限・支払条件）を足してもらう
13〜15分記録とダッシュボード（2分）：drill_log.md に1行。ダッシュボードに1枚足す（下記）

使うプロンプト例

受注データ.csv の直近1か月から、受注の多い顧客を3社選んで、
それぞれの見積のたたき台を Excel（.xlsx）で3ファイル作って。
項目は「品目・数量・単価・小計・消費税・合計」。単価は CSV の単価を使う。
研修当日の見積ファイルが残っていれば上書きせず、ファイル名の末尾に _w2 を付けて。
作る前に、分からない点（消費税率、宛名の形式、有効期限）を先に私に聞き返して。

直すとき：

3ファイルとも、合計の下に「有効期限：発行日から30日」「支払条件：月末締め翌月末払い」の2行を足して。
数字は変えないで。

ダッシュボードに1枚足す

その週の結論と数字が、ダッシュボードの「受注と見積」に入ります。

今週（第2週）のドリルの結果を、ダッシュボードに1枚足して。

作る前に、次の4つを先に私に見せて、私の答えを待って。
① 結論（1〜2文）
② 数字（4つまで。どのファイルのどの行・どの列から取ったか。計算した数字は計算式も）
顧客名・個人名は、前提メモの「名前の扱い」に従う。
③ 次の一手（何を、誰が、いつまでに）
④ 人が決めること（1つの問い）と、いまの状態（未決・決定・保留）
専門家（社労士・税理士・弁護士）に確かめた方がよい点があれば、それも1つだけ挙げて。無ければ挙げない。

私が「OK」と言ったら、ファイルを読み直さずに、見せた内容のまま、次の2つだけを行って。
・dashboard/data/w（2桁の週番号）-（今の日付と時刻 YYYYMMDD-HHMM）.js を新しく作る
・dashboard/index.html の「WEEKS:END」の行のすぐ上に、<script src="data/そのファイル名"></script> を1行足す
既にあるファイルは書き換えない・消さない。同じ週をやり直したときも、新しい日時のファイルを足す（新しいものが表示される）。

ファイルの形（この形のまま埋める）
DASH.add({
  week: 2,
  date: "YYYY-MM-DD HH:MM",
  practice: （練習データなら true、自社の数字なら false）,
  title: "",
  conclusion: "",
  numbers: [ { label: "", value: 数字, unit: "", note: "" } ],
  source: "",
  next: { action: "", owner: "", due: "" },
  decision: { status: "（未決／決定／保留）", question: "", note: "" },
  expert: { topic: "", question: "" }
});
専門家に確かめる点が無ければ、expert の行は入れない。
